Install or upgrade through KiCad

  1. Open KiCad Manager’s Plugin and Content Manager. Under Manage Repositories, add the WayriCAD repository feed. Its address stays the same between releases.
  2. Refresh the repository and install or update the individual tools you need. For this release, choose 4.8.8. You do not need to install every plugin.
  3. For a manual install, download the matching -PCM.zip below and use Install from File. Do not unpack a PCM ZIP into a second plugin folder.
  4. Restart the affected KiCad editor and verify the installed version. Save the intended board before launching an analysis; unsaved changes are not included.

KiCad 10 is the documented baseline. Follow the version-matched installation guide and compatibility matrix for your plugin and OS. A PCM installation is separate from a full suite CLI installation.

QuickTherm: powers, then Run

  1. Save the PCB, including its current zone fills. Open WayriCAD QuickTherm.
  2. In Components, review actual dissipated watts and the parts included in the study. A maximum rated power is not operating dissipation. Unknown selected powers remain actionable errors.
  3. Leave Automatic setup enabled and click Run. The built-in solver chooses the supported layered model when a physical saved stackup is available; otherwise it uses an explicitly labelled thin-sheet screen. It also chooses the starting mesh. Normal screening does not require CalculiX.
  4. Review ambient, material and cooling assumptions. Blank starting values use documented illustrative defaults, including 20 °C ambient. Edited values and explicit component scope are retained; no selection includes available valid known powers.
  5. Inspect solved/selected counts, excluded or unknown inputs, board temperatures and heat balance. Use Files to save the study, reports and computed results. Thermal workspace inputs do not change the source PCB.

Choosing an explicit model or manual mesh leaves automatic mode. Older saved studies reopen with their advanced choices preserved; re-enable Automatic setup to use the normal flow. Unsupported layer-dependent physics and conflicting boundaries are errors, rather than silent model substitutions.

Explore and share the same saved design

4.8.8 retains the 4.8.7 Review and Portable Web Export refresh: occurrence-aware schematic hierarchy, BoM and part lookup, linked PCB/3D selection, Photoreal Fast, expanded-board net inspection and improved orbit/pan behavior. What was checked, and what remains unknown

The 4.8.8 release records all eight hosted CI jobs passing and 326 native QuickTherm tests plus 223 subtests passing, with three optional CalculiX/Gmsh integration skips. The public thermal example and real KERO Encoder PCB passed the normal native window/worker Run flow with illustrative powers and ambient. All 27 installed plugin payloads were hash-verified; the installed QuickTherm run used its own runtime rather than a source-checkout fallback.

These checks establish execution and conservation evidence for those cases, not measured thermal accuracy. Automatic mesh sizing does not establish convergence. Board temperature is not junction temperature; junction values remain unknown without package thermal data. Layer-dependent physics still needs physical stackup information. STEP geometry and board colors do not supply missing material or cooling properties.
