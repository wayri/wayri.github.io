07 / Follow the copper

See the path behind a net.

Select a trace or use Inspect → Nets to search saved net names. Associated copper is highlighted while unrelated geometry dims. Turn off “Highlight entire net” for object-only selection. Hidden layers stay hidden.

Read-only preview. Missing component models use approximate stand-ins, not verified mechanical geometry. The viewer does not edit designs, run ERC/DRC or execute simulation solvers. Local files opened here are read in your browser, not uploaded by this page.

Advanced / Project workspace

Two drawings. One place to inspect.

Search the project and compare schematic, PCB and 3D panes.

Loads on request; the compact demo above stays available.

Navigate: search Files, Parts or Nets. Choose the active pane before opening a drawing. Saved child-sheet links open listed project sheets; unresolved links stay disabled.

Compare: switch between split and single panes. Open a driver schematic in one pane and the PCB or 3D view in the other. Link parts uses unambiguous saved symbol identities between loaded drawings.

Read-only, with no comments or annotation editor. Component linking does not infer identity from reference labels. Nets remain local to their drawing: matching short names across sheets are not proof of connectivity. Approximate 3D model notices still apply.

Embed the Advanced viewer
const project = new KiCadWebView.AdvancedKiCadViewer('#project', {
  theme: 'dark', layout: 'split', linkedSelection: true
});
await project.load('/assets/lib/kicad-webview/demo/project.json');
// Give #project an explicit height, e.g. 760px.
// project.dispose() releases both panes when leaving.

Start with two elements.

Self-host the script and project files. No Node runtime is needed on the host server or in the visitor’s setup.

<script src="https://wayri.github.io/assets/lib/kicad-webview/kicad-webview.min.js"></script>
<kicad-viewer
  src="https://wayri.github.io/assets/lib/kicad-webview/demo/project.json"
  style="display:block;height:500px">
</kicad-viewer>
Or use a few lines of JavaScript
const viewer = new KiCadWebView.Viewer('#board');
await viewer.load('/assets/lib/kicad-webview/demo/project.json');
viewer.setInspectorOpen(true);
// Give #board an explicit height, e.g. 500px.

For another site, use the full project URL or host your own copy. Cross-origin sources must permit CORS. See the license before integrating commercially.

Imported analysis · Beta

Explore a field
on the board.

Illustrative data only. The demo is a deterministic interface example, not an electrical or thermal solve, measurement or validation of this inverter.

Load a sample overlay in the live viewer above. Switch fields, adjust opacity and probe cells to see values with their units. Pan and zoom keep the overlay aligned with the board.

Use Analysis in the viewer for visibility, fixed colour scale, opacity and run assumptions. Layer-linked fields follow saved layer visibility; 3D pauses the overlay. Results must match the exact PCB source hash.

No PI, SI or thermal solver runs here. A direct SPIKE / Quick PI exporter is a future integration.
