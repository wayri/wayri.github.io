05 / Explore in 3D

Turn the layout into a board.

Drag to orbit; scroll to zoom. Named views, orbit, tilt, roll and zoom buttons also work in compact embeds. Focus the viewer to use 1 / 2 for top / bottom, 0 for isometric and Shift + arrows to rotate. Use Measure for surface distances. Missing models use approximate stand-ins.

06 / Check fabrication

Inspect the fabrication geometry.

Toggle IRCA’s exported layers in Layers. Select drill geometry for tool attributes, or use the ruler for a two-click measurement in mm.

07 / Follow the copper

See the path behind a net.

Select a trace or use Inspect → Nets to search saved net names. Associated copper is highlighted while unrelated geometry dims. Turn off “Highlight entire net” for object-only selection. Hidden layers stay hidden.

Read-only preview. Missing component models use approximate stand-ins, not verified mechanical geometry. The viewer does not edit designs, run ERC/DRC or execute simulation solvers. Local files opened here are read in your browser, not uploaded by this page.

Advanced / Project workspace

Two drawings. One place to inspect.

Search the project and compare schematic, PCB and 3D panes.

Loads on request; the compact demo above stays available.

Navigate: search Files, Parts or Nets. Choose the active pane before opening a drawing. Saved child-sheet links open listed project sheets; unresolved links stay disabled.

Cross-probe: keep Link selection enabled, then select a component or pad whose schematic sheet is open in the other pane. Saved symbol identities link components; a PCB trace does not select an unrelated schematic net. Try component cross-probe opens and locates a uniquely matched IRCA component in both drawings.

Share: Create view link in the viewer toolbar captures the loaded drawings, cameras and selection. Opening that URL restores the same saved revision automatically.

Read-only, with no comments or annotation editor. Component linking does not infer identity from reference labels. Nets remain local to their drawing: matching short names across sheets are not proof of connectivity. Approximate 3D model notices still apply.

Link independent embeds, too.

Use linkViewers([schematic, board, assembly]) to connect separate viewers in an article or application. Saved component identities link schematic and PCB selection; matching board views can also share exact pads, copper objects and nets. Each camera stays independent. Source-bound view links restore supported cameras, layers and selections after the host loads the same saved revision.

Linking does not guess electrical connectivity from matching labels. Dispose the link group when its viewers unmount.

Scripted 3D presentations

Full-color TFT & virtual controls.

Graphics and input attached to the actual displayed geometry.

Paint an OLED, LCD, matrix or full-color TFT surface, drive a virtual LED, and respond to buttons, knobs or viewer-scoped keys. The host supplies the graphics and behavior; the saved design stays unchanged.

Load IRCA, then choose a component face for the virtual display.

Display console

A virtual full-color graphics surface, not firmware running on IRCA.

Loads on request. Choose a planar component face to mount the display.

Display graphics can come from canvas drawing, images or pixel buffers. Pointer input returns surface coordinates; keys act only while the viewer is focused.

These are virtual presentation effects. They do not execute firmware, emulate an electrical bus, connect to hardware or run a solver. Choosing a face does not establish that the part is a physical display. Source or view replacement suspends the controls.

Independent project tree

See how the sheets fit together.

A source-derived hierarchy without mounting a 3D viewer.

Explore saved root and subsheet instances, expand branches and export a portable SVG diagram. IRCA is a single-sheet example; choose your own multi-sheet schematics or ZIP to explore a larger hierarchy locally.

Load the single-sheet IRCA example or open your local project.

Local files are read in your browser without uploading them.

The diagram represents saved sheet relationships, not a complete electrical netlist. Missing, ambiguous, cyclic or truncated links remain labelled. SVG export contains the diagram only; it does not export the original native design files.

Embed the same IRCA review.

This example uses the viewer plus this site’s IRCA review adapter. The adapter loads derived review geometry and display models; it is separate from the native viewer API.

<script src="https://wayri.github.io/assets/lib/kicad-webview/kicad-webview.min.js"></script>
<script src="https://wayri.github.io/assets/js/irca-project.js"></script>
<div id="board" style="height:500px"></div>
<script>
(async () => {
  await IRCAProject.ready();
  const viewer = IRCAProject.createViewer('#board', { theme: 'dark' });
  await IRCAProject.load(viewer, { view: 'pcb' });
})();
</script>

IRCA / Computed study

IRCA copper
DC study.

A normalized 1 A unit load on IRCA’s saved 3.3 V regulator-to-controller rail, with 35 µm copper. Device operating currents were not documented; this is a copper-model example, not a measured operating condition.

Open the calculated study to see its numeric summary.

Quick PI computed this field offline from the saved IRCA copper. The browser displays the result; it does not run a solver.

The interactive overlay samples actual FEM triangles with strictly interior patches covering 31.15% of their area. Gaps are not zero-valued copper. The complete field is shown below.

The coupled front/back copper model includes plated barrels at 20 °C with assumed 25 µm plating. It excludes regulator dynamics, switching, package/contact resistance, the loaded return path and thermal feedback. Final voltage drop changed 0.472% under mesh refinement; local current-density hotspots are not qualified.
