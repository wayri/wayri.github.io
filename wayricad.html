Install WayriCAD in KiCad

  1. Open Plugin and Content Manager from KiCad Manager. Open Manage Repositories and add the feed below.
  2. Select the WayriCAD repository and install an individual plugin. Alternatively, download a matching -PCM.zip release asset and choose Install from File; do not unpack it manually.
  3. Follow the plugin’s runtime setup instructions. For IPC tools, enable KiCad’s API and configure Python as described in the installation guide. Scientific tools can require additional native dependencies.
  4. Restart the editor, open and save your project, and launch the installed action. Review inputs and previews before any apply/export step.

Illustrated installation guide · Python and offline runtime setup · Troubleshooting

KiCad 10 is the documented baseline. KiCad 11 integration is in progress; check the compatibility matrix rather than assuming every engine or OS is supported. Initial dependency preparation may need internet access. No single install command supplies every scientific/native runtime.

Automation

CLI automation and KiCad jobsets

The source/CLI installation exposes tool entry points independently of the desktop windows. A PCM plugin install is not a complete suite CLI installation. Use the maintained guide to prepare the required interpreter, then inspect the available commands:

wayricad --help
wayricad-rlc --help
wayricad jobs --help

Jobsets run your chosen analysis and export steps in a sequence, with a linked local report, logs and JSON evidence. Preserve source hashes, units, assumptions and nonzero exit codes when integrating with CI or external engineering assistants. Successful execution is not engineering approval.

Using the results

Understand the model limits

Inputs can include saved copper, stackup, terminals, declared power and material values. A matching net name is not a verified return path, and a screenshot is not a measurement. Missing or unsupported terms must remain visible.

Choose the right analysis

DC voltage drop, thermal screening, transmission-line estimates and full-wave electromagnetic studies have different assumptions. Do not substitute one model for another or treat nominal protocol targets as certification.

Preview and validate changes

Use the affected plugin’s preview, backup and apply workflow. Re-run native KiCad DRC/ERC where relevant and review manufacturing requirements independently. Offline edits and live editor transactions have different safeguards.

Contribute, report a bug, or follow development

WayriCAD is GPL-3.0 open-source software maintained by Yawar / Wayri. A useful bug report includes the plugin and release, OS, KiCad/Python versions, exact steps, logs, and a minimal non-private fixture. Remove private board names, paths and credentials before sharing screenshots or reports.
