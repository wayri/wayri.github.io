What you can do in KiCad Online

Open repository projects or local files
Start from GitHub, GitLab, or a local file or folder. Use the project chooser to find the drawing you need in a repository with several hardware projects.
Trace a net through the design
Follow a selected signal through saved schematic sheets and copper layers, then inspect the matching pads in 3D. Focus a single layer when overlapping copper hides the route.
Make review findings easy to locate
Anchor comments to a drawing, part or region so reviewers can return to the same place. Use the grouped BoM to check fitted parts and assembly information.
Review fabrication and simulation outputs
Inspect Gerber copper, outlines and Excellon drills before handoff. Open saved waveform samples, compare cursor readings and keep the result with its source design.

What you can build with KiCad WebView

Put a saved design in a webpage
Embed a compact PCB viewer in documentation or expand it into a wider workspace. Readers can zoom, inspect saved layers, and switch between the worksheet, board outline, and full layout.
Connect drawings and page controls
Link schematic and PCB selections so one click locates the same component in both. Wire page controls to WebView so a hover can highlight a part and a click can show its saved properties.
Explore the assembly in 3D
Orbit a model-backed board to inspect the underside and component spacing. Explode the display to see how copper layers and components sit relative to one another.
Bring saved results into a review page
Pair an embedded schematic with a host plot of retained KiCad SPICE outputs. With WayriCAD results, show saved copper voltage and temperature fields on the matching PCB.
