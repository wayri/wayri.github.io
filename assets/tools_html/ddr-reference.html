DDR timing & routing

A bench-side guide to the timing vocabulary and routing groups. Use the exact controller, DRAM speed grade, package and memory topology to set constraints.

Clock cycles are not nanoseconds

For a double-data-rate data bus, tCK (ns) = 2000 / data rate (MT/s). One data transfer interval is half a clock period. A 3200 MT/s bus has a 0.625 ns clock period; CL22 corresponds to 13.75 ns of CAS latency. This is arithmetic, not total system memory latency.

Route groups, not one giant length-matched bus

GroupConnectionsRouting intent
DQ + DM/DBI + DQS pairData group associated with its strobeMatch delay within the controller-defined byte/nibble group; preserve DQS pair symmetry.
CK pairController clock to memoryUse the topology, termination and skew budget for the chosen population.
Address, command, controlShared command pathDDR4 examples use fly-by; do not copy that rule blindly to another generation or topology.
VREF, VTT, suppliesReferences, termination supply and powerFollow generation-specific sourcing, decoupling and reference-plane guidance.

Match propagation time, including package contributions, rather than copper length alone. Different layers and via transitions introduce different delays. Keep reference planes continuous, transitions consistent and tuning compact. Confirm permitted bit swaps with the memory-controller documentation before changing pin order.

There is no universal “DDR = 100 Ω and ±5 mil” rule. For example, AMD’s cited Versal DDR4 guide specifies 50 Ω single-ended and 90 Ω differential for its stated stackup assumptions. TI has a different device-specific routing table. Import the rules for your controller, package and board.

Routing basis: TI AM65x/DRA80xM DDR guidelines, AMD DDR4 connections, AMD DDR4 physical rules, and Altera delay matching guidance.

Before bring-up

  • Reconcile controller-supported memory, ranks, widths, rails and speed grade.
  • Extract per-group delay, impedance and via counts from the actual stackup.
  • Check reset, clock, references and termination before investigating training.
  • Use the controller’s memory-test and training reports; a successful boot alone does not measure timing margin.

DDR3/4/5 and LPDDR families differ in signaling, channels, training and power requirements. This sheet provides vocabulary and a review sequence, not interchangeable layout constraints.
