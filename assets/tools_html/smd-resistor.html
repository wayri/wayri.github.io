Standards

3-Digit: First two digits are significant figures, third is multiplier ($10^x$). 'R' indicates decimal. Tolerance is not determined by this nominal code.

4-Digit: First three digits are significant, fourth is multiplier. 'R' indicates decimal. Tolerance is not determined by this nominal code.

EIA-96: Two digits (code for value from EIA-96 table) followed by a letter (multiplier). Check the part datasheet for tolerance.

Decodes common nominal markings, not a component identification or tolerance guarantee. Vendor-specific markings can differ. EIA-96 multipliers supported here: Z, Y, X, A–F. Decimal R codes are treated as decimal notation; ambiguous aliases are intentionally not inferred.
