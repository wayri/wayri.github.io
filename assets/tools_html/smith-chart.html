Equations, assumptions and references

Γ = (Z − Z₀)/(Z + Z₀); z = Z/Z₀; y = Z₀/Z; VSWR = (1 + |Γ|)/(1 − |Γ|); RL = −20 log₁₀|Γ|. Series elements add impedance; shunt branches add admittance. ZL = j2πfL; ZC = 1/(j2πfC).

Passive finite R ≥ 0, positive real Z₀ and frequency. Components are ideal and lumped. No parasitic models, transmission lines, frequency-dependent load data, stability, losses in L/C or power ratings are inferred. A good input match with resistors may dissipate power: low reflection alone does not establish efficient transfer to the load.

Reference: Analog Devices — impedance matching and Smith chart impedance. Chart values are normalized; use the exact interface and component requirements for a design.
