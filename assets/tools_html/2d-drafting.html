Math & Theory

Vector Graphics: Shapes are stored mathematically as vectors (lines, rectangles) rather than pixel maps, allowing infinite scaling without loss of resolution.

Distance Calculation: Euclidean distance $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$ is used to display dynamic dimensions while drafting.
