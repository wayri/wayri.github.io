Atmosphere and ground assumptions

DNI = extraterrestrial normal irradiance × τ1/sin(elevation); a 0.01 minimum sine bounds the near-horizon approximation. DHI = entered fraction × (extraterrestrial normal irradiance − DNI) × sin(elevation). This returns only part of the attenuated beam as diffuse light, keeping horizontal irradiance within the extraterrestrial energy bound. These are declared scenario assumptions, not a calibrated Hottel model or an atmospheric forecast. Sky diffuse and reflected-ground irradiance use isotropic view factors.

Search evaluates only this explicitly assumed scenario.

The search checks a 5° tilt / 15° azimuth grid, then a 1° local refinement, under the selected model. It is a bounded numerical search, not a global optimum or a recommendation for weather, roofs, shading, structural loading or installation cost. The main monthly/annual chart integrates all calendar days at 15-minute midpoints; the search uses weighted representative days for speed.

Advanced: supplied interval data

1. Interval data → power and energy

The starting data is an analytic constant-irradiance test fixture, not site weather. Replace it with measured or documented model inputs for a site study.

Relative schema: time_h,duration_h,poa_w_m2,ambient_c,cell_c. Absolute schema: start_iso,end_iso,poa_w_m2,ambient_c,cell_c with Z or an explicit UTC offset. Every row describes its entire interval; values are treated as constant interval means. Duration is never inferred from the next row. Use cell_c for supplied-temperature mode, or ambient_c for the NOCT approximation. Optional wind_m_s is retained but not used.

Supplied-data equations, input contract and limits

Interval DC: Pdc = PSTC × (GPOA/1000) × [1 + γ(Tcell − 25)] × (1 − Ldc). γ is converted from %/°C to 1/°C. Available AC = Pdc × ηinv; delivered AC = min(available AC, inverter AC rating). Energy = Σ(power in kW × explicit duration in hours). This is a linear nameplate model with constant inverter efficiency; it does not reproduce the complete PVWatts model.

Optional NOCT-linear approximation: Tcell = Tamb + (NOCT − 20) × GPOA/800. It scales the nominal test-condition rise with irradiance; it does not model wind, mounting, thermal inertia or calibrated module behavior. Supplied effective cell temperatures are preferred. It is not a thermal-design or safety tool.

Monthly estimate before clipping = DC kWp × POA kWh/m²/day × month days × representative temperature factor × DC remaining fraction × inverter efficiency. AC rating is deliberately not used for monthly clipping: a daily irradiation total is insufficient to calculate it.

Overlaps, duplicate starts, missing duration, nonfinite or negative irradiance are rejected. Gaps are reported and not filled. ISO results use UTC for completeness and day selection. Relative times cannot establish an annual result. A complete Jan 1 → next Jan 1 UTC interval series with no gaps is required for an interval annual total; all 12 monthly inputs are required for a monthly annual estimate. No short-period annualization or weather fallback is performed.

Provider timestamps may represent instantaneous samples, preceding-hour totals or interval means. Convert to this explicit interval-mean schema using the provider’s documentation before import. The location workflow above is a separate declared geometric scenario with a bounded angle search, not synthetic expected weather. Battery dispatch, economics, IV/MPPT, spectral, bifacial and snow-cover models are not implemented.

Primary references and obtaining data

NREL PVWatts v5 technical manual for the nameplate/irradiance/temperature model basis; this implementation uses a simpler constant-efficiency inverter.

Sandia PVPMC — NOCT model describes a fuller model with mounting and wind corrections; the optional linear screening approximation here omits those corrections.

JRC PVGIS output definitions: H(i)d is daily global POA irradiation in kWh/m²/day. Open PVGIS to obtain location-, orientation- and database-specific inputs. This page does not silently fetch, resample or invent weather data.
