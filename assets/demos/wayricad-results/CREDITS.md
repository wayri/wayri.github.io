# WayriCAD public saved-result examples

Source: https://github.com/wayri/WayriCAD/tree/0617fd201c0817d95648cec639744138aa59fe20/docs/examples/pocket-kivi

Retained native boards, project settings, result JSON, numerical provenance and upstream GPL-3.0 notice are copied from that revision without numeric/coordinate changes. These are generated saved-board example producer outputs under declared assumptions, not measured hardware or a production design. The SI eye is illustrative; missing samples remain missing. No solver was rerun for the WebView demo. The viewer software uses MPL-2.0; upstream example/design terms remain separate.

The upstream README records input models, mesh/model limits, exact PCB hashes, producer versions and execution environment: https://github.com/wayri/WayriCAD/blob/0617fd201c0817d95648cec639744138aa59fe20/docs/examples/pocket-kivi/README.md

Original producer metadata spelling (including legacy encoded unit strings) remains retained. Plotted units follow the known producer field conventions; no numeric unit conversion is performed.
