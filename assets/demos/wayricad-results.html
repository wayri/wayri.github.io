Public WayriCAD generated example inputs, pinned 0617fd2. Computed producer outputs under declared assumptions; the eye display is illustrative. These are not measurements or a production design. Unknown values remain missing. The original source data and models are not changed by viewing.

Credits, evidence and display limits

The example is a public two-layer 30 × 15 mm board; SI uses the saved complete-channel derivative. The result hash must match the loaded PCB before registration is enabled. Independent 3D fields retain declared source coordinates and elevations; the matching-PCB field overlay is 2D. Grid preview cells are not clipped to board or copper boundaries. Missing elevation and unsupported shapes remain 2D data.

Full result arrays remain in the numerical data browser and JSON download. Display selection and point limits remain visible. Local files stay in your browser; source paths inside results are never fetched. Review metadata before sharing.
